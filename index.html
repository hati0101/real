REAL SERVER

확률 안내

실제 서버에서 현재 접근 가능한 확률형 콘텐츠만 추려 공개합니다. 탭에서 분류를 선택하고, 확률순 정렬 또는 상세보기를 이용할 수 있습니다.

안내 이 페이지는 사용 로그가 아니라 소스·로드 설정·플레이어 접근 경로를 기준으로 합니다. 실제 계정별 사용 횟수, 몬스터 스폰, SQL 보상값은 별도 운영 DB 검증 대상입니다.

운영 확률

현재 로드 및 접근 경로가 확인된 확률 요소를 전부 표시합니다.

15개

확률 정렬은 명확한 숫자 범위가 있는 항목만 비교합니다. 높은순은 최대값, 낮은순은 최소값 기준이며 DB별·가중치형·시간형 항목은 뒤에 배치됩니다.

확률형 상자·아이템

현재 공급 경로가 확인된 4개 계열만 공개합니다.

4개

가중치표가 현재 추림 문서에 없는 상자는 확률순 비교에서 뒤에 배치됩니다. 구성품별 정확한 확률은 원본 부록 기준입니다.

공개 기준

페이지에 포함하거나 제외한 기준입니다.

2026-09-16

포함 기준

현재 map-server가 기동 중이고, 해당 코드 또는 NPC가 현재 설정에서 로드되며 플레이어 접근 경로가 확인된 항목만 포함합니다.

제외 기준

주석 처리, 비활성 플래그, 클라이언트 데이터만 존재, 획득 또는 진입 경로 미확인 항목은 제외합니다.

검증 범위

소스와 로드 설정으로 “현재 이용 가능” 여부까지 확인합니다. 실제 계정별 사용 횟수·몬스터 스폰·SQL 보상값은 별도 검증이 필요합니다.

공개용 운영 원칙

DB/스폰이 미검증된 공급 경로는 공개 확률표에 확정 정보처럼 추가하지 않습니다.
